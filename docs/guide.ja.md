# Kataribe ガイド

README に書いていない使い方をまとめています。

## 話させる

1. 入力欄に、話してほしいことを書いて Enter を押します（例:「寝る前に小さなうさぎの話をして」）。
2. 止めるまで話し続けます。止めるときは Esc を押します。
3. 途中で「もっとゆっくり」「別の話にして」と送ると、次の行から変わります。
4. 「」で囲んだ文は LLM を通さずにそのまま読みます。

## 声

- 依頼の中に「低く落ち着いた男性の声で」のように書くと、その声で話します。
- 気に入った声は入力欄の上の「声を登録」で名前を付けて残せます。
- 声の名前を押すと、新しい声や登録した声に切り替えられます。
- 依頼で声を指定しないときの声は、設定の「既定の声」で決められます。

## 履歴

左上のボタンで、前の会話の一覧が開きます。会話を選ぶと、同じ声で続きから話します。

## 設定

右上の歯車から開きます。

- 音声合成のモデル: speech.cpp で使えるモデルから選びます。読み上げる言語もここで選べます。
- 声を作るエンジン: speech.cpp のほかに [audio.cpp](https://github.com/0xShug0/audio.cpp) も選べます。audio.cpp では、`audiocpp_server` の実行ファイルと Irodori-TTS の GGUF（Anime 版など）の場所を入れます。最初の画面の「セットアップ」を押すと、audio.cpp と声のモデル（約 1.1GB）が自動で入ります。
- LLM: Claude Code、Codex、LM Studio から選び、「接続テスト」で確かめます。Claude Code と Codex にログインしていないときは、画面に「ログイン」が出ます。
- 文章の書き方: LLM に渡す指示を書き換えられます。「既定に戻す」で元に戻せます。

## 主なキー

| キー | 動作 |
|---|---|
| Enter / Shift + Enter | 送信 / 改行 |
| Esc | 一時停止 |
| Ctrl + Space | 一時停止と再開の切り替え |
| Ctrl + , | 設定を開く |

キーは設定の「キーボードショートカット」で変えられます。

## コマンドで動かす

起動中の Kataribe に、ターミナルから指示を送れます。

```bash
python server.py send "寝る前に、小さなうさぎの話をして"
python server.py say "今日もおつかれさま。"
python server.py pause
python server.py status
```

ほかの操作は `python server.py --help` で確かめられます。

## 開き方

| 付けるもの | 開き方 |
|---|---|
| なし | Kataribe の窓で開きます |
| `--browser` | いつものブラウザで開きます |
| `--port N` | ポートを変えます（既定は 7865） |
